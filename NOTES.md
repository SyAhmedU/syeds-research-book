### 21. syeds-research-book/ — Syed's Research Book
**Reference-tier** browsable corpus — **9,388 papers** (DOI-deduped) × **167 management/OB constructs**, Scopus-graded; the suite's literature spine, from Syed's hand-coded 24-month workbook ([[project-research-corpus]]; workbook NOT committed, 27MB). Single-file `index.html`, fetches `data/*.json` (needs HTTP). **No-fab: every record is Syed's coding, transformed not invented; gap-fill only from real DOI records.**
- `scripts/` (PS+Node, no AI): `convert-xlsx.ps1` (xlsx→JSON) → `split-data.ps1` (eager index + lazy abstracts) → `enrich-abstracts.mjs` (OpenAlex/Crossref, resumable, `--merge`).
- `data/`: `papers.json` (canonical) · `papers.index.json` (eager) · `abstracts.json` (lazy, 7,236 = 77%, `absSrc` provenance, ~2,150 unavailable) · `constructs.json` (167+vocab) · `constructs.recent.json` (**618 machine-extracted construct phrases** from the recent tier — `scripts/mine-constructs-recent.mjs`, verbatim linguistic-frame extraction, no AI, ≥10-paper gate; 195 crosswalk to hand codes, 423 new; Constructs view hand⇄recent toggle, badged "machine · verify", click→Library `?q`; smoke `_srbconstructs.mjs`) · `constructs.map.json` (**crosswalk** construct→theories/scales: `scripts/build-construct-map.mjs` label-matches Book vocab × TheoryScope `constructs[]` × ScaleScope `construct` — 99 codes + 184 phrases linked; "🧠 N · 📏 N" chips → modal w/ links out, also on Library paper-modal construct chips; consumed in REVERSE by TheoryScope+ScaleScope modals and Studio Frame/Measure; re-run after catalog changes) · `memberships.json` (16,408 edges) · `summary.json` · `recent.dissections/<NNN>.json` (256 shards — AI dissections of the recent tier, written by papercards `dissect-corpus.mjs --tier recent`, read by PaperCards matrix).
- **6 views** (`VIEWS`+`setView`/`#v-<view>`): Library (filters + `#q`, 50/pg; supports `F.constructs[]` = AND-intersection filter, shown as a removable `#xfilterNote` chip) · Constructs · Map · Trends (construct×year heatmap) · **Term Trends** (folded Wordmap over `data/words.json` — 425 terms, 9 subfields; click term → Library; canonical home, RF `_WORDMAP_DATA_URL` → here) · Overview. **Map = 6-mode toggle in the shared modebar** (`MX.mode`; `renderMap()` dispatches): **Graph** (force web) · **Matrix** (pick 2–3, the precise read) · **Chord** (top-N on a ring, ribbons=co-occurrence, `renderChord`) · **Clusters** (research "camps" = `mxCamps` hub-grouping, `renderClusters`) · **Neighbours** (one construct→ranked partner bars, `renderNeighbors`) · **Heatmap** (readable top-40 labelled camp-ordered DOM grid, `renderHeatmap`). Each over a **3-tier toggle** (`mxSetTier`): **Hand-coded** (167 Book codes, verified moat) · **+ Recent** (also counts the recent single-fetch-tag tier) · **Recent corpus · 408** (DEFAULT on first Map open). Graph = the force web; **Matrix = construct×construct co-occurrence heatmap** — pick 2–3 constructs (palette reuses the `.spec-*` CSS), cell = # papers coding both, readout shows the pair/triple intersection, click a cell → Library filtered to that pair.
  - **Recent-corpus construct pipeline (NO AI, No-fab; the matrix/graph rebuild — constructs must be real measured concepts, not sentences/methods/geos):** `scripts/build-construct-lexicon.mjs` merges **ScaleScope's 310 validated construct names + Syed's 167 Book constructs** (cleaned atomic labels via `LABEL_OVERRIDE`; ~33 non-constructs `DROP_CODES`'d; Book identifiers fold in as match synonyms) → **`data/construct-lexicon.json` (408 clean constructs)** → `extract-construct-memberships.mjs` scans all **79,517** recent papers' title+abstract (verbatim word-boundary) → **`construct-memberships.json`** (real multi-construct sets — 56,709 papers ≥1, 40,186 ≥2; replaces the single fetch-tag) → `build-cooccurrence.mjs` → **`construct-cooccurrence.json`** (13,787 pairs). In-page: lazy `CC`/`loadCorpus()`; corpus-tier branches in `mxNm/mxTopDefault/mxPartners/mxCompute/mxMulti/mxLeadsData/renderGraph(→renderGraphCorpus)`; drill-down (`ccOpenPapers`→`F.dois` exact DOI set) badged "recent corpus · machine-matched · verify". Leads gaps = ≤2 co-occurrence among the **top-100** prominent (corpus tier).
  - **Shared viz data layer** = `mxHeatData()` (tier-aware: ordered constructs + `valOf(i,j)` + `pairs`/`adj`, cached `MX._heat[key]`) feeds Chord/Clusters/Neighbours/Heatmap. `mxCamps(D)` = deterministic research camps (diverse hub seeds at normalised-cooccurrence <0.04, assign each construct to its strongest hub; No-fab — groupings from counts only); `mxClusterOrder` reorders the heatmap so camp-mates block together. All drill via `vizDrill`→`ccOpenPapers`/`mxOpenPapers`. The old full-pixel canvas heatmap was **replaced** (user: "dizzy, no meaning") by these. **`⬇ Excel` export** (always-visible in modebar; `exportMatrixExcel`, lazy SheetJS cdnjs) → 3 sheets: Constructs · Pairs (long, 13,787) · full square Matrix; tier-suffixed filename.
  - Re-run the three build scripts after a catalog change. Local browser smoke `_srb_corpus_smoke.mjs` (puppeteer-core from `_mobile-audit`, 14 checks). **Coverage/gap layer (all from real counts, NO sign invented):** cells classed studied (pink intensity) · `under` (studied but lift = obs/expected < 0.35, amber inset) · `gap` (◆ violet = both constructs ≥30th-pct prominent yet 0 co-occurrence = research white-space) · `empty` (not studied); legend + note state plainly **colour = how much, NOT direction** — the corpus codes co-occurrence, not effect sign. **Positive/negative/mixed is deliberately NOT colored** — no corpus-wide signed relationship data exists (papercards dissections cover ~1.4% as free-text prose), so painting sign would violate No-fab. Counting only (No-fab safe). **Leads panel** (`mxLeadsData`/`renderMxLeads`, corpus-wide over all constructs, cached per tier) under the grid = 3 ranked clickable lists: **Strongest pairs** (top co-occurrence count) · **Most under-studied** (both in the top-50 prominent set, expected≥5, lift<0.5, ranked by lift, shown "N× under") · **Biggest gaps** (top-50 prominent pairs with 0 co-occurrence, biggest first); strong/under rows → Library AND-filtered, gap rows → put the pair on the grid. **Replaced the never-finished Spectrum view** (its `renderSpectrum` was never defined — dead nav button removed). Modal → PaperCards `#seed=<doi>` (+`#explain=<doi>` 🎬 when abstract on file) + DOI/OA/RG/CP/SciHub links. `?view=<v>` deep-link. Smokes `srb_smoke.mjs`+`_srbtt.mjs`+`_srbmatrix.mjs`.
- **OpenAlex refresh / Recent tier:** `scripts/refresh-openalex.mjs` (`--mode construct|journal`) fetches real 2024→ papers (gates: identifier-term verbatim + real journal). Output STAGED to `data/openalex-refresh/`, tagged `addedVia:'openalex-*'` — **never merged into the hand-coded `papers.index.json` (verified moat stays clean).** `scripts/merge-refresh.mjs` → `data/recent.index.json` + sharded `recent.abstracts/<NN>.json` — **self-preserving** (seeds from committed tier first), **purges repository deposits** (`REPO_VENUE` regex). Library: recent tier ON by default (opt-out `localStorage.srb_recent`), badged "↑ recent"; **⚡ live layer** (`fetchLive()`) pulls newest ~45-day works on construct pick / 4+ char search, badged "⚡ live". Map/Trends/Overview stay hand-coded-only (`p._recent` skipped). One-shot `scripts/run-refresh-today.cmd` (detached, resumable). Construct *assignment* on fetched tiers = machine/heuristic, marked.
